# Earthy Notes

Landing page for **Earthy Notes**, a plant-themed stationery shop.

Built with React, Vite, and Tailwind CSS, with smooth-scroll interactions powered by Lenis.

## Tech stack
- React
- Vite
- Tailwind CSS
- Lenis (smooth scroll)

## Sections
- Hero, Story, Philosophy, and First Batch showcase the shop and products
- Newsletter signup
- Shop banner generation script for Etsy listings
